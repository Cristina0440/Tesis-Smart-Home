# 🏠 Tesis: Análisis y Visualización de Consumo Energético en Hogares Inteligentes

Este proyecto es una aplicación web desarrollada con Streamlit que permite visualizar datos de consumo energético en hogares inteligentes. Forma parte de la tesis de ingeniería de software enfocada en el análisis y predicción de patrones de consumo mediante tecnologías emergentes.

---

## 🚀 Características

- Visualización interactiva de consumo energético por dispositivo, hora y día.
- Análisis de patrones de uso y detección de hábitos.
- Preparado para integrar modelos de Machine Learning (opcional).
- Interfaz sencilla y accesible a través de Streamlit.

---

## 🛠️ Tecnologías usadas

- Python 3.10+
- Streamlit
- Pandas, NumPy
- Matplotlib / Plotly (si usas)
- Scikit-learn (si aplicas modelos)
